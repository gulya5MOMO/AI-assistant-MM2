# 🕊️ MM2 Trade Assistant

Точный калькулятор окупаемости трейдов для Roblox Murder Mystery 2.
Работает **полностью локально** — без интернета. Твои трейды — только твои.

🌐 **Наш официальный сайт:** https://mm2-trade-assistant.vercel.app/

---

## 📖 Что это

**MM2 Trade Assistant** — лёгкий десктопный помощник для трейдеров в Roblox Murder Mystery 2.
Берёт твою базу цен из `mm2_prices.txt`, разбирает текст трейда и моментально выдаёт вердикт.
Вердикт озвучивается голосом.

---

## ✨ Возможности

- 🧮 **Точный расчёт** — считает по твоей базе цен из `mm2_prices.txt`
- 🔊 **Озвучка вердикта** — голосом сообщает результат
- 🕊️ **Работа в трее** — сидит рядом с часами, меню по правой кнопке (Показать / Скрыть / Выйти)
- 📂 **Открытый код** — можешь залезть внутрь и переделать под себя
- 💸 **Бесплатно навсегда** — без подписок, активаций и «премиум-версий»
- ⚡ **Работает стабильно** — запускается мгновенно, работает офлайн

---

## ⚠️ Важно знать

Софт считает **только по твоей базе** `mm2_prices.txt`.
Если предмета там нет — он не сможет его распознать.
Всегда заноси новые предметы в базу, и расчёт будет точным.

## 🚀 Быстрый старт

### Шаг 1. Скачиваем и распаковываем

Скачай архив `MM2_Trade_Assistant.zip` и **обязательно распакуй его** (правый клик → «Извлечь всё»).

### Шаг 2. Запускаем помощника 🕊️

После распаковки идём по такому пути:

```
MM2_Trade_Assistant/
└── dist/
    └── PigeonTradeAssistant/
        └── PigeonTradeAssistant.exe
```

Запускаем `PigeonTradeAssistant.exe` — и в скрытых значках (трее, возле часов) появится иконка голубя.
Нажимаем на неё **любой кнопкой мыши** — хоть левой, хоть правой.

**Управление в трее:**
- 🖱️ **ЛКМ** — показать окно
- 🖱️ **ПКМ** — меню: Показать / Скрыть / Выйти полностью

### Шаг 3. Заполняем базу цен

Для заполнения цен заходим в **эту же папку**, где лежит `PigeonTradeAssistant.exe` — рядом будет файл `mm2_prices.txt`.

Открываем его и вставляем свои цены. Я оставил там **3 примера** — можешь удалить их и вписать свои в том же формате:

```
Chroma Evergreen      Chroma    48,000
Chroma Candleflame    Chroma     4,200
Chroma Lightbringer   Chroma       420
```

Готово — софт готов считать твои трейды!

### Шаг 4. Если пишет «не удалось распознать»

Если помощник выдаёт ошибку по типу **«не удалось распознать скины на экране»** или что-то подобное — значит предмета нет в базе цен.

В таком случае идёшь в папку `MM2_Trade_Assistant`, где лежит `main.py` (главный файл кода) — рядом с ним тоже есть `mm2_prices.txt`. Меняешь цены там — и всё, софт начнёт распознавать предметы.
