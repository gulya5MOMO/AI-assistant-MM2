# 🕊️ MM2 Trade Assistant

Точный калькулятор окупаемости трейдов для Roblox Murder Mystery 2.
Работает **полностью локально** — без интернета. Твои трейды — только твои.

🌐 **Наш официальный сайт:** https://mm2-trade-assistant.vercel.app/

---

## 📖 Что это

**MM2 Trade Assistant** — лёгкий десктопный помощник для трейдеров в Roblox Murder Mystery 2.
Берёт твою базу цен из `mm2_prices.txt`, разбирает текст трейда и моментально выдаёт вердикт.
Вердикт озвучивается голосом.

---

## ✨ Возможности

- 🧮 **Точный расчёт** — считает по твоей базе цен из `mm2_prices.txt`
- 🌐 **Русский + английский** — понимает названия предметов на двух языках
- 🔊 **Озвучка вердикта** — голосом сообщает результат
- 🕊️ **Работа в трее** — сидит рядом с часами, своё меню по правой кнопке
- 📂 **Открытый код** — можешь залезть внутрь и переделать под себя
- 💸 **Бесплатно навсегда** — без подписок, активаций и «премиум-версий»
- ⚡ **Работает стабильно** — запускается мгновенно, работает офлайн

---

## ⚠️ Важно знать

Софт считает **только по твоей базе** `mm2_prices.txt`.
Если предмета там нет — он не сможет его распознать.
Всегда заноси новые предметы в базу, и расчёт будет точным.

## 🚀 Быстрый старт

### Шаг 1. Скачиваем и распаковываем

Скачай архив `MM2_Trade_Assistant.zip` и **обязательно распакуй его** (правый клик → «Извлечь всё»).

### Шаг 2. Запускаем помощника 🕊️

После распаковки идём по такому пути:

```
MM2_Trade_Assistant/
└── dist/
    └── PigeonTradeAssistant/
        └── PigeonTradeAssistant.exe
```

Запускаем `PigeonTradeAssistant.exe` — и в скрытых значках (трее, возле часов) появится иконка голубя.
Нажимаем на неё **любой кнопкой мыши** — хоть левой, хоть правой.

### Шаг 3. Пишем названия предметов в `mm2_prices.txt`

Открой файл `mm2_prices.txt` по этому пути:

```
C:\Users\имя пользователя\Desktop\MM2_Trade_Assistant
```

Там и вписывай названия предметов и их цены. Я оставил **3 примера** — можешь удалить их и вписать свои в том же формате:

```
Gold Gingerscythe    Unique    500M
Голд Джинджерсайт    Unique    500M
Gold LogChopper      Unique    500M
Голд ЛогЧоппер       Unique    500M
Gold Minty           Unique    500M
Голд Минти           Unique    500M
```

> 💡 Софт понимает названия предметов **только на двух языках: русском и английском**. Впиши оба варианта — так помощник точно распознает предмет, на каком бы из этих двух языков он ни назывался.

Готово — софт готов считать твои трейды!

### Шаг 4. Если скажет ошибку

Если помощник выдаёт ошибку по типу **«не удалось распознать скин»**, **«не нашёл»** или что-то подобное — значит либо предмета нет в базе цен, либо это ошибка нашего помощника.

**Сначала посмотри** — есть ли предмет в `mm2_prices.txt`. Если нет — просто добавь его.

Если предмет **есть в базе, а ошибка всё равно остаётся** — значит это ошибка нашего помощника. В таком случае напиши в Discord разработчика: **momoshka0735**.

> ⚠️ Также есть редкая проблема с русским языком — но она встречается крайне редко и почти невозможна.

### Шаг 5. Управление помощником 🎮

В трее (рядом с часами) у иконки голубя есть **меню самого помощника** — там такие пункты:

| Пункт меню | Что делает |
|---|---|
| **Показать / Скрыть** | Показать или спрятать кнопку помощника |
| **Показать кнопку** | Показать кнопку обратно на экране |
| **Скрыть кнопку** | Спрятать кнопку с экрана |
| **🌐 Язык голоса** | Выбрать язык озвучки |
| **🎯 Сбросить положение кнопки** | Вернуть кнопку на стандартное место |
| **📥 Скачать цены из интернета** | Подгрузить базу цен из сети (скачаются **не все** цены) |
| **Выйти (полностью)** | Полностью закрыть софт |

**Как двигать кнопку:** зажми **ПКМ** (правую кнопку мыши) и перетащи её туда, куда нужно.

**Как посчитать трейд:** нажми **ЛКМ** (левую кнопку мыши) на кнопку **«Анализ трейда»** — помощник посчитает и ответит.
